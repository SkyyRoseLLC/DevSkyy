Visual priority

  1. Face: recognizable identity and expression.
  2. Hair: silhouette and recognizable curls.
  3. Hands: shape and visible fingers.
  4. Clothing silhouette: proportions, construction, logos and seams.
  5. Major folds: retain the shapes that define the outfit.

Aggressive reduction is limited to visually safe regions identified by inspection. The numeric target never approves a loss of identity.

Actionable production sequence

  1. Verify preserved originals and copies; import a new working copy using installed Blender/glTF/Draco support.
  2. Confirm skin, bones, textures, clips, axes and transforms before any optimization.
  3. Keep an untouched reference; create and inspect an isolated candidate near the target range.
  4. Review face, hair, hands, silhouette, folds and deformation in the same website poses and camera.
  5. Export only to the candidate directory; measure size, topology, compatibility and runtime performance.
  6. Obtain independent review and founder disposition before any runtime wiring or poster replacement.
