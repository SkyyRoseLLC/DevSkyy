# SkyyRose V2 Native Scroll World Production Gate

This is the executable contract for the new native Scroll World, built beside
the historical candidate-only handoff without changing the original handoff's
source records or preserved founder scenes.

Each of Black Rose, Love Hurts, and Signature has exactly three ordered roles:
two hero-derived native world moments followed by its exact collection-specific
pre-order scene. The authoritative role, exact SKU cast, exact CTA, and source
contract are declared in the theme manifest. The gallery cannot choose a random
collection product by rail index.

The five-world environment prompt pack remains archived context. It has no
runtime fallback path in this contract. Until all three roles of a collection
are hash-bound, independently reviewed, founder-approved, and flagged
wireable, the theme renders no native scene media for that collection.

## V2 dual-cast product authority mission

Every V2 SKU must finish with two distinct full-body on-model authority shots:
one women-led and one men-led. Both begin as candidate-only source-stage media
created from hash-bound physical product references, each with its own genuine
alpha matte and receipt. A candidate does not count as coverage until it passes
independent product-fidelity visual QA and founder review; rejected candidates,
generic renders, and unbound legacy on-model files never count.

## Required re-entry order

1. Repair the current 33-SKU on-model intake registry binding and revalidate it.
2. Build and approve the women-led and men-led on-model authority pair for
   every V2 SKU from founder-supplied exact product sources; retain genuine
   garment/accessory mattes and re-hash every original and output.
3. Bind the exact protected hero authority, including the missing Signature
   Oakland/Bay landmark authority, then complete full-size optical measurements.
4. Run the local source receipt and native-scene preflight before one approved
   Higgsfield upload. GPT Image 2 creates the candidate world around the source;
   Seedance may only create the reviewed forward-motion leg after the still
   passes independent QA.
5. Create a hash-bound independent native review and obtain founder promotion
   for every role. Only then change the production manifest to
   `FOUNDER_APPROVED_WIREABLE`, populate the local asset/review/approval fields,
   and allow gallery wiring.

Founder authorization permits paid, candidate-only source-stage and scene
generation. It does not authorize promotion, theme wiring, staging,
publication, or deployment; every output remains quarantined until its
independent visual QA and founder review pass.
